Assistance : Carnio

Aide de Carnio, carnet de bord de vos véhicules pour iPhone et iPad.

Questions fréquentes

  • Données : elles restent sur l’appareil et dans votre iCloud privé ; le développeur ne voit rien.
  • Rappels : autorisez les notifications dans Réglages de l’iPhone › Notifications › Carnio.
  • Import : ouvrez un carnet .carnio exporté par CarbuFrance ou CarbuEspaña, ou touchez le bouton d’ajout d’un plein sur la fiche d’une station.
  • Export : le CSV et le rapport PDF d’un véhicule se partagent depuis l’app.
  • Abonnement : « Sans pub » dans les Réglages de l’app, ou Réglages de l’iPhone › votre nom › Abonnements.
