À propos de cette page

ChromaTraque est un jeu de déduction pour iPhone et iPad : un Grison invisible vole les gâteaux de Chromaterre, et Gloup, la petite créature aux grands yeux, l’écoute et fouille la bonne case avant la fin des tours. Cette page est la page d’assistance officielle du jeu, celle déclarée à Apple sur la fiche App Store.

Ce que vous trouverez ici

  • Où est enregistrée votre progression : sur l’appareil, avec une copie dans votre iCloud si iCloud est activé, sans compte ni serveur du développeur.
  • Comment jouer : écouter, puis fouiller la bonne case.
  • Que faire si vous ne trouvez pas le voleur : l’aide Déduction, les gadgets, la vidéo « +3 tours ».
  • Comment gérer les rappels : Réglages › Jeu › Rappels.
  • Comment changer de langue : Réglages › Jeu › Langue, 45 langues.
  • Que faire si vous n’entendez aucun son : volume, commutateur silencieux, puis Réglages › Audio.
  • Pourquoi des publicités, et comment modifier votre consentement.
  • Comment restaurer vos achats : Boutique › Offres › Restaurer mes achats.
  • Comment fonctionne l’énergie.
  • Comment supprimer vos données : Réglages › À propos › Supprimer mes données.
  • Comment nous écrire si le problème persiste.
